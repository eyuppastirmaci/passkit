# passkit

A command-line password generator with a small local vault.

## Usage

```
passkit gen [OPTIONS]
passkit passphrase [OPTIONS]
```

See `passkit <command> --help` for all options.

The passphrase wordlist is the [EFF large wordlist](https://www.eff.org/deeplinks/2018/08/dragon-con-diceware), CC-BY 3.0.
